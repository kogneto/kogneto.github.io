# andrewdeloose.com

Personal site for [andrewdeloose.com](https://andrewdeloose.com): a single hand-written `index.html` with one small stylesheet (`css/site.css`) and no build step, hosted on GitHub Pages from the `master` branch.

To preview locally, serve the repo root with any static file server, e.g. `python -m http.server`, then open http://localhost:8000/.
